# 传感器漂移

## 我的当前理解

传感器漂移是指传感器的响应特性随时间发生变化，使相同气体和浓度在不同时间得到不同的信号分布。

## 为什么重要

如果模型主要使用早期数据训练，而部署时传感器响应已经改变，训练分布与测试分布会发生偏移，导致识别或浓度预测性能下降。

```text
相同气体与浓度
→ 不同时间产生不同响应
→ 训练数据与部署数据分布不一致
→ [[电子鼻模式识别]]性能下降
```

## 与系统的关系

漂移可能同时影响[[气体传感器阵列]]的原始响应、[[电子鼻信号处理]]的特征稳定性和最终模型的跨时间泛化。
