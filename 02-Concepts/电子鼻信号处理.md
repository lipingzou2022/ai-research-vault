# 电子鼻信号处理

## 我的当前理解

电子鼻信号处理位于传感器阵列和模式识别模型之间，负责把多通道、随时间变化的原始电学响应转换成可用于分析和学习的数据表示。

## 处理主线

```text
[[气体传感器阵列]]原始响应
→ 放大、滤波、补偿等模拟信号调理
→ ADC 与多通道采集
→ 数字信号预处理
→ 响应曲线分析
→ 人工特征提取 / 选择，或自动表示学习
→ [[电子鼻模式识别]]
```

## 三种处理路线

```text
分步式：原始信号 → 预处理 → 人工特征提取 → 特征选择 → 传统模型
端到端：原始或轻度预处理信号 → 深度网络自动学习表示 → 任务输出
混合式：人工构造部分特征 → 神经网络继续学习高级表示 → 任务输出
```

端到端不等于完全不做滤波、基线校正或标准化。当前最有用的区分是：关键判别特征主要由人预先定义，还是围绕最终任务随模型共同学习。

## 气体响应曲线

一次典型过程可能包含空气阶段、气体进入、响应变化、相对稳定、停止通气和恢复。曲线反映传感器对气体的动态反应，而不只是一个静态数值。

## 当前已知特征

- 最大响应值；
- 稳态响应；
- 响应时间；
- 恢复时间；
- 曲线积分面积；
- 指数拟合参数；
- 指数移动平均特征；
- 小波变换特征。

新综述的阶段性阅读进一步将传统特征提取分为：

- 手工设计特征：峰值、峰峰值、响应 / 恢复速度、RMS、偏度、峰度等；
- 拟合估计特征：用多项式或指数函数等拟合响应曲线，再把拟合参数作为特征；
- 频域特征：论文已列为一类，但具体指标尚未读到。

动态特征可能使用导数，而导数容易放大局部噪声。中值滤波、小波方法和[[Autoencoder|降噪自编码器（DAE）]]是当前阅读中出现的信号改善或重建方法，其适用条件仍需后续核对。

## 降维与可视化的角色

PCA 等方法可能作为预测流水线中的降维步骤，也可能只把高维特征映射到二维 / 三维供人观察。可视化中同类聚集或类别分离不能单独证明模型预测性能，仍需独立测试指标。

## 关键区分

原始响应曲线是采集到的时序信号；上述统计量或变换结果是从曲线中构造出的特征。深度学习也可能直接学习原始或较少处理的时序表示，但其优势需要结合数据规模和评价协议验证。
