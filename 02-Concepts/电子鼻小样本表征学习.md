# 电子鼻小样本表征学习

> [!summary] 一句话理解
> 电子鼻小样本表征学习不是一种固定算法，而是研究在标注样本有限时，如何借助合理的数据变化、相关旧数据、无标签数据、少样本任务训练或组分知识，学到能够泛化到新样本甚至新类别的表征。

## 我的原始疑惑

- 电子鼻为什么特别容易出现小样本问题？
- 数据增强、预训练—微调和元学习都在解决数据少，它们有什么本质区别？
- Autoencoder 为什么可以用于预训练 Encoder？
- Episode、N-way K-shot、Support Set 和 Query Set 分别是什么？
- 孪生网络为什么共享两个 Encoder，它学习的是类别还是样本相似性？
- 大量组分气味为什么可以帮助少量混合气味？Focal Loss 在这里解决什么问题？

## 我的当前理解

电子鼻样本通常来自真实配气、采样、清洗与恢复过程，获取成本高且速度慢。样本少而模型参数多时，模型容易记住训练样本及其偶然噪声，导致过拟合和新样本性能下降。

```text
标注样本少
→ 可用于约束模型的证据有限
→ 深度模型容易拟合训练细节
→ 泛化能力下降
```

本问题的核心不是简单追求更多网络层，而是：**如何在有限标注条件下，让 Encoder 学到对目标任务有用且能够迁移的表征 `z`。**

## 四条主要解决路线

| 当前限制 | 主要路线 | 利用的额外信息 |
| --- | --- | --- |
| 已有样本太少，但可定义合理变化 | Data Augmentation | 同一样本的标签保持变换 |
| 目标数据少，但相关旧数据较多 | Pretraining–Fine-tuning | 旧数据中的可迁移参数与表征能力 |
| 新类别只有少量参考样本 | Meta-learning | 大量模拟的少样本任务经验 |
| 混合气味少，但组分气味数据多 | 组分知识辅助 | 组分数据与混合数据之间可能共享的信息 |

[[Autoencoder]]预训练属于预训练路线的一种实现：它进一步利用大量无标签数据，通过重构目标先训练 Encoder。

## Data Augmentation：制造合理变体

### 核心思想

对已有真实样本施加不改变语义的合理变换，形成更多训练输入。当前综述讨论总结中出现的方式包括：

- 截断；
- 增益变化；
- 幂函数映射。

```text
真实响应信号
→ 合理变换
→ 新训练样本
→ 告诉模型同类气味允许一定变化
```

它不是凭空产生新的气体知识，而是把研究者认可的“不变性”写进训练数据。其局限是人工增强只能覆盖有限变化；变换过强还可能改变真实类别或破坏物理意义。

### 实验边界

数据增强只能根据训练数据执行。若先对完整数据增强，再划分训练集与测试集，同一原始样本的近似副本可能同时落入两边，造成数据泄漏和虚高结果。

## Pretraining–Fine-tuning：迁移相关旧知识

目标任务数据很少，但存在大量相关旧数据时，可以先预训练 Encoder：

```text
大量相关旧数据
→ 预训练 Encoder
→ 学习通用信号处理与表征参数
→ 少量目标数据
→ 微调任务头或部分 Encoder
```

常见微调方式包括：

1. 冻结 Encoder，仅训练新的任务头；
2. 保留预训练参数作为初始化，小幅更新部分或全部 Encoder，并训练新任务头。

迁移的不是旧类别名称本身，而是模型参数中已形成的特征提取能力。能否迁移取决于源任务与目标任务是否共享有用信息；域差异过大时也可能出现负迁移。

## Autoencoder 预训练：利用无标签数据

当相关数据很多但缺少标签时，可以先执行：

```text
无标签电子鼻数据
→ Encoder
→ z
→ Decoder
→ 重构输入
```

再把训练好的 Encoder 用于少量有标签数据：

```text
保留预训练 Encoder
→ 接入新任务头
→ 冻结或微调 Encoder
→ 完成分类 / 回归
```

这说明 [[Autoencoder]] 可以成为“预训练 Encoder”的一种手段，但重构得好不保证表征一定最适合分类。是否有效仍需与随机初始化、直接监督训练和其他预训练方式公平比较。

## Meta-learning：训练“用少量样本学习”的能力

### 为什么还需要它

若新类别只有 1～5 个样本，常规微调可能不稳定。元学习在训练阶段反复构造少样本任务，让模型练习如何根据少量参考样本建立类别概念，因此常被概括为 Learning to Learn。

### 关键概念

- **Episode**：一次模拟的小样本任务。
- **N-way**：一次任务需要区分 `N` 个类别。
- **K-shot**：每个类别提供 `K` 个有标签参考样本。
- **Support Set**：少量带标签的参考样本，用于描述当前任务中的类别。
- **Query Set**：需要模型判断的样本，用于计算预测与训练损失。

例如，`3-way 2-shot` 表示一次 Episode 中有 3 个类别，每类仅提供 2 个 Support 样本。

### Meta-training

```text
已有训练类别
→ 反复采样 Episode
→ Support 提供少量类别参考
→ Query 用于任务内评价与计算 Loss
→ 共享 Encoder 产生 z
→ 更新 Encoder
```

对于度量式方法，可让同类表征更接近、异类表征更远，使模型逐渐学会从少量参考样本形成判断规则。

### Meta-test

```text
训练阶段未见的新类别
→ 每类提供少量 Support
→ Encoder 得到参考表征

新 Query
→ Encoder 得到 z_query
→ 与各类参考表征比较
→ 预测类别
```

严格评估时，Meta-training 与 Meta-test 的类别通常需要按设定分离；否则不能证明模型具备面向未见类别的少样本泛化能力。

## Siamese Network：学习两个样本是否相似

孪生网络使用参数共享的两个分支：

```text
样本 A → 共享 Encoder → z_A
                            ↘
                              距离 / 相似度
                            ↗
样本 B → 共享 Encoder → z_B
```

两个 Encoder 参数共享，本质上是在不同输入上重复使用同一个特征提取器。训练目标通常鼓励同类样本表征更近、不同类更远，因此模型重点学习“两个样本像不像”，而不只是记住固定的类别输出层。

当前阅读总结指出综述中的 DeepSniffer 使用了孪生网络思想；其具体网络、损失、数据划分与效果仍需回到综述原文及对应原始论文核验。

## 组分知识辅助混合气味识别

当单一组分气味数据丰富，而[[混合气体识别|混合气味]]样本稀少时，可以尝试共同利用两类数据：

```text
大量组分气味数据
+ 少量混合气味数据
→ 共同训练或迁移
→ 利用可能共享的组分信息识别混合气味
```

例如乙醇和丙酮单组分数据很多、乙醇—丙酮混合样本很少时，组分数据可能提供部分可复用表征。但混合响应可能存在非线性与交互作用，因此不能默认“混合气味等于组分表征简单相加”。

## Focal Loss 与类别不平衡

大量组分样本和少量混合样本共同训练时可能形成 Class Imbalance（类别不平衡）。Focal Loss 的核心机制是降低已经容易正确分类样本的损失贡献，相对突出仍然难分类的样本：

```text
容易且已高置信度正确分类的样本
→ 降低影响

仍容易出错的困难样本
→ 保留较大影响
```

少量混合气味样本如果同时较难识别，可能因此获得更多相对关注。不过，“少数类”与“困难样本”不是同义词；Focal Loss 也不是所有类别不平衡问题的自动答案，仍需与类别权重、重采样等方案比较。

## 容易混淆的概念

- **小样本问题与元学习**：小样本学习是一类问题；元学习只是其中一条方法路线。
- **数据增强与新增真实知识**：增强编码已有的不变性假设，不会自动创造新的实验条件。
- **预训练与微调**：预训练学习可复用参数，微调用少量目标数据适应新任务。
- **Autoencoder 与监督预训练**：前者可以用无标签重构任务预训练，后者直接依赖有标签任务。
- **元学习与普通微调**：元学习在训练阶段就反复模拟少样本任务；普通预训练—微调主要依靠预训练参数再适应目标任务。
- **Siamese Network 与两个独立模型**：两个分支共享权重，本质上是同一个 Encoder 的两次调用。
- **Focal Loss 与类别权重**：Focal Loss主要依据样本当前难易程度调整贡献，不等同于固定给少数类更大权重。

## 本次纠正的错误理解

1. **小样本学习就是一种固定算法。** → 错误。它是问题设定，可由增强、迁移、元学习等不同路线处理。
2. **增强样本越多越好。** → 不准确。增强必须保持标签和物理合理性，还要避免数据泄漏。
3. **预训练就是记住旧类别。** → 不完整。希望迁移的是参数和表征能力，但是否真正可迁移需要验证。
4. **Autoencoder 重构得好，分类一定也好。** → 不保证，重构目标与判别目标可能不同。
5. **元测试的新类别在元训练时已经见过。** → 在面向新类别的标准设定中，元测试类别应与元训练类别分离。
6. **孪生网络有两个互不相关的 Encoder。** → 错误，两个分支通常共享参数。
7. **Focal Loss 就是少数类加权。** → 不准确，它主要降低容易样本的影响并突出困难样本。
8. **混合气味可以由组分气味简单相加得到。** → 不一定，交叉敏感和非线性响应可能破坏简单可加假设。
