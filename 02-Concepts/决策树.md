# 决策树：从 ID3、C4.5 到 CART、回归树与剪枝

> [!summary] 一句话理解
> 决策树在训练时反复选择最合适的“特征 + 阈值”来切分训练数据；分类树希望切分后类别更纯，回归树希望目标数值更接近。新样本预测时只需沿已学好的条件走到叶节点，得到类别或该叶节点的代表数值。

## 本次学习定位

这是继 [[KNN]] 后学习的第二个传统机器学习算法。KNN 的重点是“新样本像谁”；决策树的重点是“新样本满足哪些条件”。它把此前的 `X / y`、`fit()`、`predict()`、分类、回归、过拟合和泛化等概念放进了一个可解释的规则学习过程。

```text
决策树简介
→ ID3：信息增益
→ ID3 偏爱多取值特征的问题
→ C4.5：信息增益率
→ CART 分类树：Gini + 二叉切分
→ CART 回归树：平方误差 + 叶节点预测值
→ 剪枝：控制复杂度与过拟合
→ scikit-learn API 与超参数
```

## 我的原始疑惑

- ID3 为什么会偏爱“学号”这类没有实际规律的特征？“按学号切分后熵小”到底是什么意思？
- C4.5 为什么需要 SplitInfo，为什么它能缓解学号问题？
- CART 算法与 CART 的二叉树结构分别是什么，CART 是否就等于 Gini？

- “把特征空间切成一块一块”在图形和预测上分别是什么意思？
- 训练样本和测试样本在回归树中各做什么；测试样本会不会重新参与求平均或重新建树？
- 决策树为什么通常不像 KNN 那样必须标准化？剪枝为什么可能降低训练分数却提高测试分数？

## 我的当前理解

### 决策树在学什么

决策树很像多层 `if / else`，但判断条件不是人工手写，而是从训练数据中学习的。

```text
当前节点的训练样本
→ 枚举候选特征与候选阈值
→ 评价每一种切分
→ 选出当前节点最好的“特征 + 阈值”
→ 形成子节点并递归重复
→ 停止生长或剪枝
```

根节点是第一个判断，内部节点继续判断，叶节点不再切分并输出预测。重要纠正：不是同一层所有节点共用同一条件；**每一个内部节点都可以学习自己的特征和阈值**。

例如电子鼻特征可以形成如下规则：

```text
最大响应值 > 2.5？
├─ 是：响应时间 > 10？
│  ├─ 是：甲醛
│  └─ 否：氨气
└─ 否：酒精
```

在 [[电子鼻模式识别]] 中，决策树可把由 [[电子鼻信号处理]] 得到的响应特征映射到气体类别、浓度或样本状态；是否有效仍要由具体数据与评价协议检验。

### 与 KNN 的核心差异

| 维度 | [[KNN]] | 决策树 |
| --- | --- | --- |
| 核心问题 | 谁和新样本最像？ | 新样本满足哪些条件？ |
| 训练阶段 | 主要保存训练样本 | 学习切分特征与阈值 |
| 预测阶段 | 计算距离、找邻居 | 沿规则路径走到叶节点 |
| 特征尺度 | 通常敏感，常需缩放 | 通常不敏感 |
| 可解释性 | 相对弱 | 较强 |
| 分类输出 | 邻居投票 | 叶节点类别 |
| 回归输出 | 邻居目标值综合 | 叶节点目标值代表值，常见为均值 |

决策树的阈值只依赖单个特征的相对顺序。例如 `age ≤ 25` 把年龄整体乘 100 后，相应阈值变为 `age ≤ 2500`，分组不变。因此它通常不需要像基于距离的 KNN 那样强制标准化；这不是说真实工程中任何预处理都永远不需要。

## 分类树：怎样让节点越来越纯

分类训练数据原本可能混有酒精、甲醛、氨气等标签。一个好的切分会让各子节点的类别更单一；“纯”表示节点内尽量只有一种类别。不同算法的主要差异之一，正是怎样定义“这一刀切得好”。

### ID3：Entropy 与 Information Gain

熵（Entropy）可以暂时理解为节点中类别的混乱程度：类别越单一，熵越小；两类数量越均衡，熵越大。

$$
H=-\sum_i p_i\log_2p_i
$$

全部同类时 $H=0$；二分类各占一半时 $H=1$。ID3 选择**信息增益**最大的特征：

$$
Information\ Gain=H_{before}-H_{after}
$$

切分后的熵必须按各子节点样本数量加权。若左、右节点分别有 8 和 2 个样本：

$$
H_{after}=\frac{8}{10}H_L+\frac{2}{10}H_R
$$

样本更多的分支应对整体混乱程度有更大影响。

### 为什么 ID3 偏爱“学号”

我这次的关键纠正是：**不是学号这个数字本身“熵小”**。问题在于学号通常人人不同；若按学号切分，每个分支可能只剩一个训练样本，于是每个子节点只有一个标签、熵为 0，切分后加权熵也趋近于 0，信息增益就会异常大。

```text
学号唯一
→ 每个子节点只含一个样本
→ 子节点标签完全纯
→ 切分后熵很小
→ ID3 误以为这是一条好规则
```

这本质是在记住训练样本，并不能回答新学号 005 会怎样，因此与过拟合直接相关。

### C4.5：为什么引入 Gain Ratio

ID3 只问“切完有多纯”，容易偏爱把数据切得过碎的多取值特征。C4.5 引入 SplitInfo，进一步问“是否靠过度分裂才得到这种纯度”：

$$
Gain\ Ratio=\frac{Information\ Gain}{SplitInfo}
$$

例如 4 个学生按学号切成 4 个分支时，若信息增益为 1、SplitInfo 为 2，则信息增益率为 0.5；按“听课状态”均分成两组，若同样信息增益为 1、SplitInfo 为 1，信息增益率为 1。C4.5 因此更倾向可泛化的“听课状态”。

一句话区分：ID3 问“切完有多纯”；C4.5 还问“是不是靠切得太碎才这么纯”。

## CART：结构、分类与回归

### CART 算法和二叉结构的关系

CART（Classification And Regression Tree）回答的是“怎样建一棵能分类或回归的树”。它在每个节点尝试候选特征和阈值、评价切分、递归建树并控制复杂度。其核心结构规则是**每次只产生两个分支**，即二叉树。

```text
CART 算法：怎样造树
├─ 如何评价切分
├─ 选择哪个特征与阈值
├─ 每次只做二叉切分
└─ 停止或剪枝
       ↓
最终得到 CART 二叉决策树
```

因此，CART 不等于二叉树本身，也不等于 Gini。Gini 是 CART **分类树**常用的切分评价指标之一；二叉结构是 CART 的结构约束；回归树则以数值误差衡量切分。

### CART 分类树：Gini Impurity

Gini（基尼不纯度）衡量类别混杂程度：越小越纯，越大越混。

$$
Gini=1-\sum_i p_i^2
$$

| 节点类别比例 | Gini | 解释 |
| --- | ---: | --- |
| 4 : 0 | 0 | 完全纯 |
| 3 : 1 | 0.375 | 有一定混杂 |
| 2 : 2 | 0.5 | 更混杂 |

CART 分类树比较每个候选切分后的**加权 Gini**，选择更小的方案。例如“认真听课”切分后两侧都纯，优于两侧仍为 `2:1` 和 `1:2` 的“是否穿黑衣”切分。

连续特征也能参与 CART。对最大响应值 `[1.0, 1.5, 2.1, 2.7, 3.0, 4.2]`，模型会尝试诸如 `≤ 1.25`、`≤ 1.80`、`≤ 2.40` 的候选阈值，并选出最优的“特征 + 阈值”。多类别特征在 CART 中也要转换为一连串二叉判断，而不是一个节点直接长出多叉。

### CART 回归树：平方误差与叶节点预测

回归任务的目标 `y` 是连续数值，不能用 Gini。CART 回归树希望同一节点内的目标值彼此更接近，常以平方误差衡量：

$$
Error=\sum_i(y_i-\bar y)^2
$$

例如房屋面积 `[40, 50, 60, 100, 110, 120]` 对应价格 `[50, 60, 70, 150, 160, 170]`。原节点总平方误差可为 15400；按“面积 ≤ 80”切分后，左右节点误差各为 200，总误差降到 400。这说明该阈值能把数值相近的样本聚到一起。

我的关键理解是：回归树不先拟合 $y=2x+10$ 这种连续公式。它把特征空间切成多个区域，每个区域对应一个叶节点和一个固定预测值，因此可看作**分段常数模型**。

```text
面积 ≤ 80        → 叶节点 A → 60 万
80 < 面积 ≤ 115  → 叶节点 B → 155 万
面积 > 115       → 叶节点 C → 170 万
```

若叶节点 A 中训练样本的价格是 `[50, 60, 70]`，则其常见预测值是平均数 60。面积为 55 的新房沿已训练好的条件进入 A，输出 60 万。

训练与预测必须区分：

```text
训练：训练数据学习切分规则；训练样本依规则落入叶节点；叶节点确定代表值
预测：测试样本只沿固定规则走；读取已确定的叶节点输出
```

测试样本**不会**重新求叶节点平均值、重新选择阈值或修改树。这正是 `fit()` 学规则、`predict()` 用规则。

| 项目 | CART 分类树 | CART 回归树 |
| --- | --- | --- |
| `y` | 离散类别 | 连续数值 |
| 结构 | 二叉树 | 二叉树 |
| 切分目标 | 类别更纯 | 节点内数值更接近 |
| 常见标准 | Gini | Squared Error |
| 叶节点输出 | 多数类别 | 目标值代表值，常见为均值 |

## 剪枝、过拟合与泛化

树无限生长时，可能把训练样本切得越来越碎，甚至接近每个样本一个叶节点：训练准确率很高，却难以泛化。剪枝（Pruning）不是简单删掉“预测错的分支”，而是控制复杂度，判断增加一段分支带来的训练改进是否值得。

| 方法 | 时机 | 当前理解 |
| --- | --- | --- |
| 预剪枝 | 生长途中 | 提前限制树继续复杂化 |
| 后剪枝 | 树长成后 | 再判断并移除不必要分支 |

常见预剪枝参数：

- `max_depth`：限制树的最大深度；
- `min_samples_split`：节点至少有多少样本才可继续切分；
- `min_samples_leaf`：切分后每个叶节点至少保留多少训练样本。

代价复杂度剪枝可粗略表示为：

$$
总代价=预测误差+\alpha\times模型复杂度
$$

在 scikit-learn 中，`ccp_alpha` 控制该后剪枝强度。它更大通常意味着树更简单；过大也可能造成欠拟合。剪枝后训练表现从 100% 降到 94%、测试表现从 80% 升到 88% 是可能的，因为目标是泛化，而非最大化训练分数。

## scikit-learn 接口

```python
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor

classifier = DecisionTreeClassifier(
    criterion="gini", max_depth=3, random_state=42
)
regressor = DecisionTreeRegressor(
    criterion="squared_error", max_depth=3, random_state=42
)

classifier.fit(X_train, y_train)
y_pred = classifier.predict(X_test)
```

| 参数 | 当前含义 |
| --- | --- |
| `criterion` | 用什么标准评价当前切分 |
| `max_depth` | 树最多多深 |
| `min_samples_split` | 节点至少多少样本才允许继续切 |
| `min_samples_leaf` | 每个叶节点至少保留多少样本 |
| `ccp_alpha` | 后剪枝强度 |
| `random_state` | 固定随机性，便于复现 |

重要边界：不能把 `criterion="entropy"` 简化等同为“完整 ID3”，也不能把 `criterion="gini"` 简化等同为“完整经典 CART 实现”。`DecisionTreeClassifier` 仍使用其自身的二叉树构建体系；这里的对应关系目前只用于理解不同切分标准的角色。

## 本次纠正的理解

1. **“学号本身熵小。”** → 错在对象。小的是按唯一学号切分后各子节点的加权熵。
2. **“CART = Gini = 二叉树。”** → 三者层级不同：CART 是建树框架，二叉是结构约束，Gini 是分类切分的常用指标。
3. **“回归树训练时人工决定样本属于哪个节点。”** → 模型先学规则，训练样本按规则自动流向子节点。
4. **“回归树预测时测试样本参与叶节点平均。”** → 测试样本只读已训练好的树，不改变叶节点或预测规则。
5. **“树越深一定越好。”** → 深树可能记住噪声；评价必须看未见数据上的泛化。
