# 序列建模基础

## 一句话理解

序列建模关注的不是孤立地处理每个输入，而是让模型利用元素的先后顺序和历史上下文形成当前表示；从 FNN、RNN、LSTM 到 [[Transformer]]，核心演进之一就是不断改进“如何保存、传递和使用上下文”。

## 这次真正卡住的问题

1. FNN 也能学习映射关系，为什么处理序列时还要引入 RNN？
2. RNN 已经有隐藏状态，为什么 LSTM 还要增加细胞状态和多个门？
3. 隐藏状态是否等于完整历史？它究竟保存了什么？
4. 单词或 CAD 命令已经可以编号，为什么不能直接把整数编号交给神经网络？
5. One-Hot 和 Softmax 输出都像一串数字，它们有什么区别？
6. “输入的数值表示”和“模型结合上下文后得到的表示”为什么不是同一件事？

这些疑惑的共同根源是：此前把“输入如何编码”“历史如何传递”“输出如何预测”混在了一起。

## 当前形成的整体框架

```text
离散符号（词、Token、CAD 命令等）
        ↓
One-Hot / Embedding：把符号变成模型可处理的数值表示
        ↓
FNN：每次主要处理固定输入，没有专门的跨时间历史状态
        ↓
RNN：用隐藏状态 h_t 压缩并传递历史信息
        ↓
LSTM：用细胞状态 C_t 和门控机制改善长期信息保存与梯度传播
        ↓
Transformer：用注意力直接建模不同位置之间的关系
```

这条路线并不表示后一个模型在所有任务上都必然优于前一个模型，而是在说明不同结构如何处理序列依赖。

## 基础对象

### 序列、时间步与 Token

- **序列（Sequence）**：具有顺序的一组元素，例如一句话、传感器时间序列或 CAD 操作序列。
- **时间步（Time Step）**：模型处理序列中某个位置时使用的索引。它不一定对应真实时间，也可以表示第几个词或第几条命令。
- **Token**：送入模型的离散基本单位，可以是词、子词、字符、命令或其他符号。

顺序是否重要取决于数据和任务。自然语言和 CAD 命令通常具有明显顺序；某些集合、图或点云任务则可能需要置换不变性，不能机械地套用序列假设。

## 输入表示：One-Hot 与 Embedding

### 为什么不能直接使用整数编号

假设三个词被编号为 1、2、3，这些编号只是身份标识。但模型可能错误地把它们解释为可比较的数值，例如认为 3 比 1 更大或距离更远。编号本身没有提供可靠语义关系。

### One-Hot

One-Hot 用一个只有目标位置为 1、其余位置为 0 的向量表示类别：

```text
猫 → [1, 0, 0]
狗 → [0, 1, 0]
鸟 → [0, 0, 1]
```

它能表达“这是哪个类别”，但向量通常维度高、稀疏，而且不同类别之间缺少可学习的相似关系。

### Embedding

Embedding 通过可训练的嵌入矩阵，把离散 Token 映射成低维稠密向量：

$$
e_t = E[x_t]
$$

其中 $x_t$ 是 Token 的索引，$E$ 是嵌入矩阵，$e_t$ 是送入后续模型的向量。

Embedding 回答的是“怎样把离散符号变成可学习的连续表示”。这个初始向量不等于模型已经结合上下文形成的表示；后者还需要经过 RNN、LSTM、Transformer 等结构处理。

### One-Hot 不等于 Softmax 输出

- One-Hot 常用于表示输入类别或监督标签，是一种编码形式。
- Softmax 输出是模型对各类别给出的概率分布，是预测结果。

例如标签可能是 `[0, 1, 0]`，模型输出可能是 `[0.05, 0.90, 0.05]`。二者形状可能相同，含义却不同。

## FNN：没有专门历史状态的基线

前馈神经网络（Feed-Forward Neural Network, FNN）中的信息从输入层向输出层传播，没有专门把上一步状态递归传到下一步的结构。

FNN 并非不能处理任何序列信息。可以把固定长度窗口拼接后交给 FNN，但这种做法通常需要预先确定上下文范围，也没有天然表达任意长度历史的状态机制。

需要避免的误解：

- FNN 与 RNN 的关键区别不是“能否泛化”；二者都可能泛化。
- 关键区别是 RNN 是否具有专门的循环状态，用于跨位置传递历史信息。

## RNN：用隐藏状态传递压缩后的历史

循环神经网络（Recurrent Neural Network, RNN）在第 $t$ 个时间步，同时使用当前输入 $x_t$ 和上一时刻隐藏状态 $h_{t-1}$：

$$
h_t = \tanh(W_xx_t + W_hh_{t-1} + b)
$$

因此，$h_t$ 可以理解为“当前输入与此前历史经过压缩后形成的当前状态”。

### 隐藏状态不是什么

$h_t$ 不是原始历史记录的完整副本。它是一个固定维度的压缩表示，会丢失信息，其内容由训练目标和模型参数共同决定。序列越长，早期信息越可能在反复变换中被削弱。

### RNN 的主要困难

- 信息需要逐步经过很多时间步，长期依赖难以稳定保存。
- 训练时可能出现梯度消失或梯度爆炸。
- 时间步之间存在顺序依赖，难以像 Transformer 那样充分并行。

“RNN”有时泛指循环神经网络家族，其中包括 Vanilla RNN、LSTM 和 GRU；具体语境中应区分狭义的基础 RNN 与整个家族。

## LSTM：用细胞状态和门控机制管理信息

长短期记忆网络（Long Short-Term Memory, LSTM）仍属于 RNN 家族。它没有简单地假设隐藏状态能够自然保留所有重要历史，而是增加细胞状态 $C_t$ 和门控机制，学习哪些信息应保留、写入和输出。

### 遗忘门

$$
f_t = \sigma(W_f[h_{t-1}, x_t] + b_f)
$$

$f_t$ 的每个分量位于 0 到 1 之间，用于控制旧细胞状态中相应信息保留多少。

### 输入门与候选信息

$$
i_t = \sigma(W_i[h_{t-1}, x_t] + b_i)
$$

$$
\widetilde{C}_t = \tanh(W_C[h_{t-1}, x_t] + b_C)
$$

输入门 $i_t$ 决定候选信息 $\widetilde{C}_t$ 中有多少写入细胞状态。

### 更新细胞状态

$$
C_t = f_t \odot C_{t-1} + i_t \odot \widetilde{C}_t
$$

这里的 $\odot$ 表示逐元素乘法。第一项保留旧信息，第二项写入新信息。

### 输出门与隐藏状态

$$
o_t = \sigma(W_o[h_{t-1}, x_t] + b_o)
$$

$$
h_t = o_t \odot \tanh(C_t)
$$

输出门决定细胞状态的哪些部分形成当前可见的隐藏状态。

### $C_t$ 与 $h_t$ 的教学性区分

- $C_t$ 更像沿序列传递的长期信息通道。
- $h_t$ 更像当前时间步对外提供的状态和输出表示。

这是一种便于理解的功能区分，并不意味着二者在模型中完全独立。

需要避免的误解：LSTM 不是“永远不会忘记”，而是通过可学习的门控机制决定保留和遗忘什么；它只是缓解长期依赖问题，并没有彻底消除所有困难。

## FNN、RNN、LSTM 与 Transformer 的关系

| 结构 | 如何处理上下文 | 主要优势 | 主要限制 |
| --- | --- | --- | --- |
| FNN | 没有专门递归状态；可使用固定窗口 | 结构直接、易并行 | 上下文范围通常需预先设计 |
| Vanilla RNN | 用 $h_t$ 逐步压缩历史 | 天然适合有序输入 | 长期依赖和梯度传播困难 |
| LSTM | 用 $C_t$、$h_t$ 和门控管理信息 | 更有能力保留长期信息 | 仍需顺序计算，结构更复杂 |
| Transformer | 用注意力直接建立位置间联系 | 长距离关系与并行训练更有优势 | 需要位置表达，计算与数据需求取决于实现和任务 |

这篇笔记是理解 [[Transformer]] 的前置基础：Transformer 不再依赖单一递归状态逐步传递全部历史，而是让不同位置通过注意力机制直接交互。

## 已纠正的误解

- “FNN 不能泛化、RNN 才能泛化” → 二者都能泛化；区别主要在序列历史结构。
- “隐藏状态保存了全部历史” → 它是固定维度的压缩表示，可能遗失信息。
- “LSTM 不会遗忘” → 它学习控制遗忘与保留，仍可能失败。
- “Embedding 就是上下文表示” → Embedding 通常只是 Token 的初始连续表示，上下文还需模型处理。
- “One-Hot 就是 Softmax” → 前者是编码或标签表示，后者通常是预测概率分布。
- “Embedding 和 RAG 是同一类方法” → Embedding 是表示机制；RAG 是利用检索结果辅助生成的系统方法，抽象层级不同。
