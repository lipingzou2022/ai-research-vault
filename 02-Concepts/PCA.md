# PCA：从降维直觉到主成分、投影、API与应用边界

> [!summary] 一句话理解
> PCA（Principal Component Analysis，主成分分析）是一种无监督线性降维方法：它在中心化后的数据中寻找主要变化方向，并把样本投影到少数这些新坐标轴上，以更少维度保留整体变化结构。

## 本次学习定位

本轮先建立“为什么需要 → 数据如何变化 → API 如何对应 → 何时失效”的完整主线，不假装已经掌握协方差矩阵、特征值分解与 SVD 的严格推导。

```text
高维 X
→ 中心化
→ 必要时 StandardScaler
→ PCA 学主成分方向
→ 投影
→ 低维 Z
→ 查看解释方差比
→ 选择 k
→ 可视化 / 分类前处理 / 聚类前处理
```

## PCA 在机器学习中的位置

PCA 是不需要标签 `y` 的无监督降维方法：

```text
Machine Learning
└── Unsupervised Learning
    └── Dimensionality Reduction
        └── PCA
```

它可在监督分类或无监督聚类之前处理输入 `X`，但 PCA 本身既不是分类器，也不是聚类器。

## 维度、冗余与降维目标

当前把“维度”理解为一个样本的特征数量。若电子鼻有 20 个传感器、每个传感器提取 5 个特征，则一个样本可表示为 100 维向量。

```text
20 个传感器 × 每个 5 个特征
→ 100 维特征向量
```

高维不是错误；问题在于特征可能高度相关、信息重复、含有噪声、计算成本较高，且不易可视化。PCA 的目标是用更少的**新特征**尽量保留数据的主要变化结构。

### PCA 不等于 Feature Selection

```text
Feature Selection：x1, x2, x3, x4, x5 → 保留 x1, x3
PCA：x1, x2, x3, x4, x5 → 重新线性组合为 PC1, PC2, …
```

因此 PC1、PC2 通常不是原来的某两列，而是原始特征的线性组合。例如：

```text
PC1 = 0.6x1 + 0.4x2 - 0.2x3 + …
```

## 为什么先中心化

中心化是对每个特征减去其训练集均值：

```text
X_centered = X - mean(X)
```

它不只是“让均值变成 0”，而是把坐标原点移到数据中心，去除整批数据整体偏移的影响，观察样本围绕平均状态如何变化。

例如 `(100, -1)、(100, 0)、(100, 1)` 中，`x` 始终为 100，真正的变化只在 `y` 方向。减去均值 `(100, 0)` 后变成 `(0, -1)、(0, 0)、(0, 1)`，主要变化方向更清楚。

### 与 CAD 点云中心化的关系

两者共同直觉是：当整体位置不是任务信息时，保留相对结构 / 相对变化会更合适。

- 点云形状识别中，可对单个物体减去质心，减少整体平移带来的干扰。
- PCA 中，对数据集的每个特征减去该特征的样本均值，为分析协方差和主变化方向建立基准。

它们的对象和目的不同。若任务是位姿估计、装配或定位，绝对位置本身可能有用，不能对每个点云或样本无条件中心化。

## 为什么有时需要 StandardScaler

PCA 用方差判断方向的重要性。不同特征的单位或数值范围差异很大时，大尺度特征可能仅因单位而带来巨大方差，从而主导主成分。

```text
收入：0 ～ 100000
传感器响应：0 ～ 2
→ 数值尺度差异可能主导方差
```

StandardScaler 通常按训练集统计量执行：

```text
z = (x - mean) / std
```

使每个特征均值约为 0、标准差约为 1，避免“单位不同”自动决定哪个方向方差最大。不同特征量纲不同、尺度差异明显，或不希望大尺度特征天然主导时，通常考虑标准化；若各特征单位相同且尺度本身有明确物理意义，则不一定必须标准化。

### PCA、KNN 与尺度敏感的差别

| 方法 | 尺度主要影响什么 |
| --- | --- |
| [[KNN]] / KMeans | 大尺度特征支配样本间距离 |
| PCA | 大尺度特征支配方差与主方向 |
| Ridge / Lasso | 特征尺度影响参数惩罚 |

`StandardScaler` 调整原有特征尺度；PCA 则构造新的主成分坐标轴，二者不是同一件事。

## 方差最大方向、PC1 与 PC2

假设要把二维点云压缩成一维。投影到点云的长轴后，样本仍然分散，保留了更多差异；投影到与长轴垂直的方向后，样本会挤在一起，丢失更多差异。

因此 PCA 令：

- **PC1**：所有方向中，投影后方差最大的方向；
- **PC2**：与 PC1 正交，并在剩余方向中投影方差最大的方向；
- 后续主成分：继续不重复已选方向，在剩余变化中按方差大小排列。

正交的作用是避免 PC2 重复记录 PC1 已经捕捉的变化。PC2 不是必然“不重要”：若 PC1 / PC2 的解释方差分别为 55% / 45%，PC2 仍然很重要；若是 95% / 5%，它相对次要。

更准确地说，“方差大 = 信息多”只适用于 PCA 的线性降维目标：它保留的是整体样本变化，并不保证保留对标签最有用的方向。

## 投影、主成分方向与 PC score

PC1、PC2 是新的坐标轴方向。将样本投影到这些轴上，得到样本的新坐标（PC score）。

```text
PC direction：一根新坐标轴的方向
PC score：某个样本在该轴上的位置
```

若二维样本 `x = [3, 2]`，PC1 方向 `v1 = [0.8, 0.6]`，则该样本在 PC1 上的投影可直观写为：

```text
z1 = x^T v1 = 3 × 0.8 + 2 × 0.6 = 3.6
```

只保留 PC1 时，二维样本用一个 score 描述，才发生 `2 维 → 1 维` 的降维。若二维数据保留 PC1 与 PC2，仍为二维，只是换了一组更贴合数据变化的坐标轴。

## 协方差、特征向量与特征值：当前直觉

- 方差：一个特征自身变化有多大。
- 协方差：两个特征是否一起变化；同涨同跌可表现为正协方差，反向变化可表现为负协方差。
- 协方差矩阵：汇总各特征自身变化与彼此共同变化的表。
- 特征向量（Eigenvector）：当前可理解为 PCA 新坐标轴的方向。
- 特征值（Eigenvalue）：当前可理解为数据沿该方向的方差，也对应主成分的重要程度。

重要纠正：

```text
错误：特征值 = 特征向量开平方
正确：特征向量表示方向；特征值表示该方向的方差；sqrt(特征值) 对应该方向的标准差。
```

协方差矩阵如何经严格推导得到特征值问题，当前仍属于 Future Learning。

## sklearn PCA 工作流

以 4 个传感器的特征矩阵为例，`X.shape = (6, 4)` 表示 6 个样本、每个样本 4 个特征：

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_train)

pca = PCA(n_components=2)
X_train_pca = pca.fit_transform(X_scaled)
X_test_pca = pca.transform(scaler.transform(X_test))
```

```text
X_train：样本数 × 4
→ StandardScaler：样本数 × 4
→ PCA(n_components=2)：样本数 × 2
```

- `fit()`：从训练数据学习均值与主成分方向。
- `transform()`：把数据投影到已经学好的主成分空间。
- `fit_transform()`：先学习，再把同一训练数据投影。
- `components_`：每个主成分在 PCA 输入特征空间中的方向系数；若先标准化，其系数对应标准化后的特征坐标。
- `explained_variance_`：各主成分所对应的方差量。
- `explained_variance_ratio_`：各主成分解释总方差的比例。

`sklearn.decomposition.PCA` 会在 `fit` 时自动中心化输入，但**不会**自动将每个特征缩放到标准差为 1；是否在 PCA 前使用 StandardScaler 仍需基于数据尺度和研究目标判断。

## 解释方差比与选择 `n_components`

假设解释方差比分别为：

| 主成分 | 单个解释方差 | 累计解释方差 |
| --- | ---: | ---: |
| PC1 | 60% | 60% |
| PC2 | 25% | 85% |
| PC3 | 8% | 93% |
| PC4 | 5% | 98% |
| PC5 | 2% | 100% |

若目标是至少保留约 90% 的总方差，应选最小的 `k = 3`。90%、95%、99% 都是经验阈值，不是普遍定律；实际选择还应看下游任务效果、可解释性、计算成本和数据规模。

```python
PCA(n_components=0.95)
```

表示自动选择尽可能少的主成分，使累计解释方差达到约 95%，并不是“保留 0.95 个主成分”。

二维可视化通常采用 `n_components=2` 来画 PC1–PC2 散点图；这不表示两个主成分一定足以支撑后续分类。

## 与分类、聚类和数据泄漏的关系

### 分类与聚类

```text
分类：X → Scaler → PCA → [[KNN]] / SVM / Logistic Regression / Random Forest → y
聚类：X → Scaler → PCA → [[聚类|KMeans]] → Cluster
```

PCA 只完成表示压缩；分类器或 KMeans 才负责预测类别或分组。特别要记住：PCA 不使用 `y`，高解释方差只说明保留了总体变化结构，**不等于**保留了同等比例的分类信息。低方差 PC 有时反而可能包含区分类别的关键差异。

### 数据泄漏与 Pipeline

错误流程是对完整数据先执行 `Scaler.fit()`、`PCA.fit()`，再切分训练 / 测试集；这样测试集已经参与了预处理规则学习。

正确流程：

```text
先划分训练 / 测试
→ Scaler 只在 X_train.fit
→ PCA 只在训练数据 fit
→ 测试集只依次 transform
→ 分类器在训练集 fit、对测试集预测
```

可使用 Pipeline 把流程绑定在一起：

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.svm import SVC

model = Pipeline([
    ("scaler", StandardScaler()),
    ("pca", PCA(n_components=0.95)),
    ("svm", SVC()),
])
model.fit(X_train, y_train)
```

## 主要用途与局限

用途：

- 高维特征的二维 / 三维可视化；
- 数据压缩与计算减负；
- 将相关特征转为相互正交的主成分；
- 为分类、聚类或其他模型提供低维输入候选。

局限：

1. PCA 是线性方法，复杂非线性流形可能无法被少数线性方向良好表示。
2. 主成分是多个原始特征的组合，物理含义通常不如原始传感器特征直观。
3. PCA 依赖方差，可能受异常值影响而使主方向偏移。
4. PCA 不用标签，最大方差方向不保证最有利于分类或回归。
5. 标准化、保留的 `k`、异常值处理及训练 / 测试划分都会改变实际结果。

## 本次纠正的错误理解

1. **PCA 是从原始数据中挑选几列。** → 错误；PCA 构造原始特征的线性组合。
2. **中心化只是把均值变成 0。** → 不完整；核心是以数据中心为原点分析相对变化。
3. **点云中心化与 PCA 中心化完全相同。** → 不准确；它们直觉相通，但对象与任务目标不同。
4. **PCA 前永远必须标准化。** → 不准确；取决于量纲、尺度与研究目标。
5. **KNN 和 PCA 怕尺度是同一个原因。** → 错误；前者主要影响距离，后者主要影响方差与主方向。
6. **PC2 一定没有用。** → 错误；应看解释方差与具体下游任务。
7. **特征值是特征向量开平方。** → 错误；特征向量是方向，特征值是该方向方差。
8. **解释方差达到 95% 就保留了 95% 分类信息。** → 错误；PCA 不使用标签。
9. **PCA 图分得开就证明分类器很好。** → 错误；仍需独立测试和指标。
