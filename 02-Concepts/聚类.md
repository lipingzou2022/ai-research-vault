# 聚类：从无监督学习到 KMeans、聚类评价与顾客分群

> [!summary] 一句话理解
> 聚类在没有真实标签 `y` 的情况下，只依据特征 `X` 中样本的相似性寻找可能的内部结构。KMeans 通过“分配到最近质心 → 计算簇内均值更新质心”的迭代得到 K 个稳定簇；簇编号没有天然业务含义，必须由人结合原始数据解释。

## 本次学习定位

这是从监督学习转向无监督学习的第一个完整算法节点。此前 [[KNN]] 中关于特征向量、欧氏距离、特征尺度和 `fit()` 的理解，能够迁移到 KMeans；但它不再学习 `X → y`，因为聚类没有训练标签。

```text
Clustering（聚类）
→ Classification vs Clustering
→ KMeans
→ Centroid 与 fit 迭代
→ 特征尺度处理
→ SSE / Inertia
→ Elbow Method / Silhouette Score
→ 原始数据回写与人工解释
```

## 我的当前理解

### 分类与聚类

| 维度 | Classification（分类） | Clustering（聚类） |
| --- | --- | --- |
| 学习范式 | 监督学习 | 无监督学习 |
| 输入 | `X + y` | `X` |
| 模型目标 | 学习 `X → y` 映射 | 寻找 `X` 内部结构 |
| 输出 | 预先定义的真实类别 | Cluster 编号 |
| 电子鼻例子 | 预测酒精 / 甲醛 / 氨气 | 无标签响应样本自动分组 |

聚类发现的是：在当前特征、距离度量和算法假设下，哪些样本彼此相似；它不自动发现客观唯一的真实类别。Cluster 编号只是算法标记，业务或科研含义必须由人查看每簇的原始特征、分布和外部证据后解释。

### KMeans 的 K 与 KNN 的 K

| 项目 | [[KNN]] | KMeans |
| --- | --- | --- |
| 学习类型 | 监督学习 | 无监督学习 |
| K 的含义 | 最近邻数量 | 预先指定的簇数量 |
| 是否有 `y` | 有 | 没有 |
| 距离的角色 | 新样本寻找相近训练样本 | 样本分配到最近质心 |

一句话：KNN 的 K 是“看几个邻居”，KMeans 的 K 是“分成几个簇”。

## KMeans：`fit(X)` 到底在学什么

KMeans（K-Means Clustering）不学习 `X → y`，而是在 `X` 中寻找 K 个稳定的 Centroid（质心）。质心可以先理解为一个簇在特征空间的平均位置。

若一簇有二维样本 `[1,2]`、`[2,2]`、`[3,2]`，逐维取平均后质心是 `[2,2]`。这也解释了名称中的 `Means`：每一轮都以簇内特征均值更新中心。

### `fit()` 的迭代过程

```text
Feature Matrix X
→ 初始化 K 个质心
→ 每个样本计算到所有质心的距离
→ 分配给最近质心
→ 得到临时簇
→ 计算每簇 Feature Mean
→ 均值成为新质心
→ 重新计算距离并重新分配
→ 反复迭代
→ 质心基本不再移动
→ 得到最终 K 个簇
```

第一次的质心并不一定在对应样本群的中心。质心更新后，样本到各中心的距离也会改变，因此有些样本会换到另一簇；簇成员变化又会导致均值与质心继续变化。只有这种“分配 → 均值更新 → 再分配”反复进行，才可能达到稳定状态。

初学时可以用“随机初始化质心”建立直觉。更准确地说，KMeans 需要初始化，初始化存在随机性；scikit-learn 默认通常使用 `k-means++`，不是唯一的完全随机摆放策略。`random_state=42` 用于控制初始化等随机过程，方便复现。

### API：训练样本与新样本

```python
from sklearn.cluster import KMeans

model = KMeans(n_clusters=3, random_state=42)
model.fit(X)

train_clusters = model.labels_
centers = model.cluster_centers_
new_cluster = model.predict(X_new)
```

| API / 属性 | 当前理解 |
| --- | --- |
| `fit(X)` | 从 `X` 学习 K 个稳定质心 |
| `labels_` | 每个训练样本最终对应的 Cluster 编号 |
| `cluster_centers_` | 最终 K 个质心的位置 |
| `fit_predict(X)` | 完成训练并直接返回训练样本的簇编号 |
| `predict(X_new)` | 将新样本分配给最近的已有质心 |

因此 `predict(X_new)` 不是预测真实类别，而是“新样本离哪个已有质心最近”。

## 特征尺度与 KMeans

KMeans 依赖距离。若年收入范围是 0 到 1,000,000，而购买次数范围只有 0 到 30，欧氏距离中的收入差可能几乎完全主导结果；聚类就会主要按收入分组，而不是按两种特征共同分组。

```python
from sklearn.preprocessing import StandardScaler

X_scaled = StandardScaler().fit_transform(X)
```

StandardScaler 的基本形式为：

$$
z=\frac{x-\mu}{\sigma}
$$

它将每个特征转换到均值约为 0、标准差约为 1 的可比较尺度，并不保证数值必定落在 -3 到 3。与 [[KNN]] 相同，尺度明显不同时常需要处理；但标准化不是无条件强制步骤。应结合特征单位、量纲与业务含义决定是否缩放、怎样缩放，或是否应保留某特征更高的权重。

## 评价聚类与选择 K

### 为什么不能直接用 Accuracy

普通无监督聚类没有真实 `y`，因此不能像分类那样把 `y_test` 与预测结果直接比较并计算 Accuracy。若数据在训练时未使用、但后来可获得外部真实类别，则可以评估聚类与外部标签的一致性；ARI、NMI 等指标尚未深入。

无标签情况下，更常问：簇内是否紧凑，簇间是否分离？

### SSE / Inertia

SSE（Sum of Squared Errors，簇内平方和）是所有样本到其所属质心距离的平方和：

$$
SSE=\sum_i\|x_i-c_i\|^2
$$

在 scikit-learn 中可通过 `model.inertia_` 查看。固定 K 时，SSE 越小表示簇内样本相对更紧凑。例如质心为 5 时，样本 `[4,5,6]` 的 SSE 为 $1^2+0^2+1^2=2$；`[1,5,9]` 的 SSE 为 $4^2+0^2+4^2=32$。

但不能直接选择 SSE 最小的 K：K 越大，簇可被切得越细，SSE 通常会继续下降；极端情况下 K 等于样本数时，每个样本自己的质心可使 SSE 为 0，却没有实际分群意义。

### Elbow Method 与 Silhouette Score

肘部法对多个 K 分别训练 KMeans、记录 SSE，再寻找“继续增加 K 的收益开始明显变小”的转折点：

```text
K = 1 → 2 → 3：SSE 降得很多
K = 3 → 4 → 5：SSE 下降开始变缓
→ K = 3 可能是候选肘部
```

轮廓系数（Silhouette Score）同时考虑一个样本是否靠近本簇、远离最近其他簇，范围为 $-1$ 到 $1$：

| 数值 | 当前解释 |
| --- | --- |
| 接近 1 | 簇内较紧凑、与其他簇较分离 |
| 接近 0 | 可能位于簇边界 |
| 小于 0 | 可能更接近其他簇 |

选择 K 应综合 Elbow、Silhouette、数据可视化与领域解释，而不是把某一个指标的最大值当作唯一真相。

```python
from sklearn.metrics import silhouette_score

labels = model.fit_predict(X_scaled)
score = silhouette_score(X_scaled, labels)
```

## 顾客聚类：从编号到人工解释

顾客数据可使用 `income` 与 `spending` 作为 `X`，但没有“高价值顾客”等训练标签。完整工作流如下：

```text
原始顾客数据
→ 选择 Feature，得到 X
→ 检查单位与尺度，必要时 StandardScaler
→ 尝试多个 K
→ KMeans.fit() / fit_predict()
→ Elbow + Silhouette
→ 选择合理 K
→ 最终 labels 写回原始表
→ groupby("cluster") 查看每簇原始特征均值 / 分布
→ 人工解释每个 Cluster 的含义
```

聚类在标准化数据上进行更适合距离计算，但标准化后的 `-1.2`、`0.6` 不便于人解释。因此应将 `labels` 写回保留原始单位的表，再使用 `groupby("cluster").mean()` 查看每个簇典型的收入、消费等特征。只有在这一步之后，人才可以谨慎命名“高收入 + 高消费”等模式；Cluster 0、1、2 本身没有固定业务等级。

## 与电子鼻研究的关系

在 [[电子鼻信号处理]] 中，多通道响应可被转换为特征矩阵 `X`。若不使用气体标签，可用 KMeans 或 PCA 等无监督方法观察样本是否自然形成群体：

```text
传感器阵列响应
→ 特征提取 / 表示
→ Feature Matrix X
→ 必要时尺度处理
→ KMeans 等无监督方法
→ 观察样本群体结构
```

若不同气体样本自然形成清晰群体，最多说明当前特征可能具备一定区分结构；它不能直接证明监督分类性能好。聚类与 [[电子鼻模式识别]] 中的监督分类评价是不同问题。

## 本次纠正的错误理解

1. **聚类会自动找到真实类别。** → 聚类只能在给定数据表示与算法假设下发现结构。
2. **Cluster 0 / 1 / 2 自带业务意义。** → 它们只是编号，语义需人工解释。
3. **KMeans 的 K 与 KNN 的 K 相同。** → 前者是簇数，后者是邻居数。
4. **KMeans `fit(X)` 没有标签就没有学到东西。** → 它在学习质心和训练样本到质心的稳定分配。
5. **SSE 最小就代表 K 最佳。** → K 增大时 SSE 自然倾向下降，必须结合更多证据。
6. **StandardScaler 对所有 KMeans 都是硬性规则。** → 应由尺度差异和特征意义决定。
7. **KMeans 能发现任意形状的簇。** → 它更适合相对紧凑、凸状、近似球状的簇；弯月形、环形、密度差异大或异常点多时可能不合适。
