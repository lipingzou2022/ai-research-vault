# CNN

> [!summary] 一句话理解
> CNN（Convolutional Neural Network，卷积神经网络）用可学习的局部窗口在有意义的维度上滑动，以参数共享的方式提取可重复出现的局部模式。

## 我的原始疑惑

- 一维卷积和二维卷积的区别是什么？
- 8 个传感器为什么仍然可以使用 1D CNN？
- Channel（通道）是什么？多个传感器是不是天然构成二维空间？
- CNN 可以处理时间序列时，为什么还需要 RNN/LSTM 或 Transformer？

## 我的当前理解

CNN 是否合适，取决于附近的一小块数据是否共同形成有意义模式，而不是数据表面上有几行几列。电子鼻中，连续若干时间点可共同表达快速上升、局部峰值、恢复片段或短时振荡，因此 1D CNN 可以沿时间轴寻找这些局部模式。

多个传感器可以作为多个输入通道。`8 个传感器`意味着 8 路同步信号，不意味着卷积必须沿两个空间方向滑动。只有传感器的二维位置本身携带可解释关系时，2D CNN 才可能自然。

## 为什么需要它

- 显式利用局部邻域关系；
- 在不同位置复用同一个卷积核，减少重复参数；
- 从原始或轻度预处理的数据中逐层学习局部到更高层的表征；
- 对位置发生小幅变化但模式相似的局部结构具有一定共享能力。

## 输入与输出

电子鼻 1D CNN 的教学形状可写成：

```text
输入：B × C × T
B：批次大小
C：输入通道，例如 8 个传感器
T：时间点，例如 1000

→ 沿时间方向卷积
→ 局部时序特征图
→ 聚合 / 分类头
→ 类别或连续数值
```

不同深度学习框架或实现可能采用不同维度顺序，实际复现时必须查看代码和接口说明。

## 核心流程与组成

```text
局部输入窗口
→ 卷积核加权组合
→ 激活函数
→ 多个位置共享同一组卷积参数
→ 可选池化或步幅下采样
→ 更高层表征
```

卷积核负责识别局部模式；通道表示同一位置上不同类型的输入信号或特征图；池化或步幅可以压缩序列长度并扩大后续单元的感受范围，但具体作用和代价仍需进一步学习。

## 容易混淆的概念

- **Channel 与卷积维度**：8 个传感器可形成 8 个通道；1D / 2D 描述卷积核沿几个有意义的维度滑动。
- **多个传感器与二维空间**：传感器在 PCB 上相邻，不代表这种几何邻接就是任务需要建模的关系。
- **CNN 与 [[GNN]] 的邻居**：CNN 邻居通常由规则网格或序列中的局部位置定义；GNN 邻居由图中的边定义。
- **CNN 与序列模型**：CNN 天然强调局部窗口；RNN/LSTM 强调顺序状态传递，[[Transformer]]强调位置间的全局交互。

## 本次纠正的错误理解

1. **8 个传感器就是二维数据，所以要用 2D CNN。** → 错误。卷积维度由有意义的关系轴决定。
2. **Channel 等于卷积方向。** → 错误。通道和卷积滑动维度是不同概念。
3. **CNN 会自动理解所有长期关系。** → 不准确。感受野可随结构扩大，但是否有效建模长程依赖仍要分析。
4. **端到端 CNN 不需要预处理。** → 不准确。去噪、基线校正、归一化与长度对齐仍可能必要。

## 与其他概念的关系

固定长度特征的组合可用 [[MLP]] 作为基线；长时间历史状态可进入[[序列建模基础]]；全局位置交互可参考 [[Transformer]]；不规则传感器关系更接近 [[GNN]] 的问题表达。
