# 线性回归：从监督学习回归任务到损失函数、参数求解与正则化

> [!summary] 一句话理解
> 线性回归属于监督学习中的回归任务：它学习权重 `w` 和偏置 `b`，以线性关系把特征 `X` 映射为连续目标 `y`；训练就是寻找让预测误差尽量小、且在需要时不过度复杂的一组参数。

## 本次学习定位

这次学习把此前零散出现的 Loss、导数、梯度、参数更新、泛化和正则化串成一条完整链。它也明确区分了三类任务：分类预测“是什么”，回归预测“是多少”，而 [[聚类]] 在没有标签时探索结构。

```text
Supervised Learning
→ Regression
→ Linear Regression
→ ŷ = wX + b
→ Loss / MSE
→ 最小二乘 或 Gradient Descent 求参数
→ MAE / MSE / RMSE 评价
→ 欠拟合 / 过拟合
→ Regularization
├─ L1 → Lasso
└─ L2 → Ridge
```

## 我的当前理解

### 回归任务与线性模型

线性回归属于监督学习，因为训练数据同时有特征 `X` 和连续标签 `y`。房价、温度、销量、压力或气体浓度通常是回归目标；“酒精 / 甲醛”或“0 / 1”是分类目标。聚类则只有 `X`，没有训练标签。

最简单的一元模型是：

$$
\hat y=wx+b
$$

其中 `x` 是输入特征，`ŷ` 是预测值，`w` 是权重，`b` 是偏置 / 截距。多特征时：

$$
\hat y=w_1x_1+w_2x_2+\cdots+w_nx_n+b
$$

因此 `fit(X, y)` 的本质是：根据训练数据找出合适的 `w` 与 `b`，让 `ŷ` 尽量接近真实 `y`。它不同于 [[聚类]] 中 `fit(X)` 寻找质心，也不同于 [[决策树]] 中学习切分条件。

### Loss：如何判断当前参数好不好

`w` 与 `b` 决定预测值，预测值决定误差，误差汇总后形成 Loss。若直接把正负误差相加，误差会彼此抵消；平方误差既避免抵消，也让大错误受到更重惩罚。

$$
MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2
$$

训练问题可以写作 $\min_{w,b} Loss$：寻找使损失尽量小的参数。MSE 越小表示当前预测整体更接近训练目标，但最终仍要在独立测试数据上看泛化。

### 导数、梯度与梯度下降

对 Loss 关于参数求导，是为了知道“轻微改变该参数，Loss 会怎样变化”。导数 / 梯度提供方向信息；它**不会自己修改参数**。实际更新由梯度下降执行：

$$
w_{new}=w_{old}-\eta\frac{\partial L}{\partial w}
$$

$$
b_{new}=b_{old}-\eta\frac{\partial L}{\partial b}
$$

其中 $\eta$ 是学习率。完整因果链：

```text
w、b
→ 决定预测 ŷ
→ 决定误差与 Loss
→ Loss 对参数求导得到梯度
→ Gradient Descent 更新参数
→ 重新预测并计算 Loss
→ 多轮迭代，Loss 逐渐下降
```

本轮数值例子：训练点为 `(x, y) = (1,3), (2,5)`，从 `w=1, b=1` 开始，模型为 `ŷ=x+1`，MSE 为 2.5。若梯度 `dw=-5、db=-3`，学习率为 0.1，则更新后 `w=1.5、b=1.3`，新 MSE 可降为 0.265。梯度为负时，更新式中的“减去负数”会使参数增大。

线性回归还可用最小二乘 / 正规方程等线性代数方法直接求解参数。当前只需区分：两者目标相同，都是让误差更小；前者强调数学数值求解，后者通过迭代逐步更新。`sklearn.linear_model.LinearRegression` 通常使用最小二乘数值求解，而非手写的普通梯度下降循环。

## 回归评价：MAE、MSE 与 RMSE

回归不是简单判断“预测是否完全相同”，而是衡量差了多少。

| 指标 | 公式 / 直觉 | 大误差影响 | 单位 |
| --- | --- | --- | --- |
| MAE | $\frac{1}{n}\sum|y-\hat y|$，平均差多少 | 相对温和 | 与 `y` 相同 |
| MSE | 平方误差平均 | 更敏感 | `y²` |
| RMSE | $\sqrt{MSE}$ | 仍敏感 | 与 `y` 相同 |

三者通常越小越好。MSE 可以在训练阶段作为 Loss，也可以在测试阶段作为 Metric；数学公式相同，但前者服务于参数优化，后者服务于模型评价。

## scikit-learn 数据流

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error

model = LinearRegression()
model.fit(X_train, y_train)

y_pred = model.predict(X_test)
w = model.coef_
b = model.intercept_
```

```text
原始 X、y
→ train_test_split
→ LinearRegression.fit(X_train, y_train)
→ 学习 w、b
→ predict(X_test)
→ y_pred 与 y_test 比较
→ MAE / MSE / RMSE
```

`coef_` 保存学到的权重，`intercept_` 保存偏置。测试集不应参与训练或预处理规则的学习，否则会造成数据泄漏，使泛化评价失真。

## 拟合、泛化与正则化

| 状态 | 训练误差 | 测试误差 | 当前理解 |
| --- | --- | --- | --- |
| 欠拟合 | 高 | 高 | 模型连主要规律都没学会 |
| 泛化较好 | 合理 | 接近且稳定 | 学到可迁移规律 |
| 过拟合 | 很低 | 明显较高 | 连噪声和偶然性也学进去了 |

线性回归不一定总是简单。样本较少、特征很多时，例如 100 个样本却有 500 个特征，模型仍可能借助噪声特征迎合训练数据而过拟合。

正则化把训练目标从“只降低误差”改为：

$$
Loss=预测误差+参数复杂度惩罚
$$

它不是保证模型更准，而是在拟合训练数据和控制复杂度之间寻求更好的泛化平衡。

### L1 / Lasso：为什么有些权重会变成 0

L1 正则化：

$$
Loss=MSE+\lambda\sum|w_i|
$$

对应 Lasso Regression。若一个很小的权重对降低误差几乎无帮助，但只要不为 0 就持续支付 `|w|` 惩罚，模型可能发现令它直接为 0 的总代价更小。L1 在 0 处有尖角，接近 0 的小权重仍受到明显收缩，因此更容易被推到 0；这使 Lasso 具有一定特征选择效果。

### L2 / Ridge：整体收缩而通常不清零

L2 正则化：

$$
Loss=MSE+\lambda\sum w_i^2
$$

对应 Ridge Regression。它通常让各权重整体缩小而非直接变 0：权重越接近 0，$2w$ 越小，继续往 0 推的作用也减弱。

| 方法 | 惩罚 | 常见结果 |
| --- | --- | --- |
| Lasso | L1，$\sum|w|$ | 部分权重可变为 0 |
| Ridge | L2，$\sum w^2$ | 权重整体缩小，通常不为 0 |

`alpha` 是 scikit-learn 中正则化强度：过小接近普通线性回归、可能仍过拟合；合适时有助于泛化；过大则可能把参数压得过头，导致欠拟合。

由于 L1 / L2 直接惩罚权重大小，而权重又受特征尺度影响，Ridge / Lasso 前通常需要注意标准化。正确的实践结构是把缩放器与模型放入 Pipeline，使每次交叉验证只在对应训练折学习缩放规则：

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge

model = Pipeline([
    ("scaler", StandardScaler()),
    ("ridge", Ridge(alpha=1.0)),
])
```

`alpha` 是超参数，可用 GridSearchCV 与交叉验证搜索；`ridge__alpha` 表示 Pipeline 中名为 `ridge` 的步骤的 `alpha`。

## 与已有知识和电子鼻研究的关系

线性回归与 [[决策树]] 的回归树都输出连续数值，但机制不同：线性回归用一条全局线性函数输出预测；回归树把特征空间切为区域，在每个叶节点给出代表值。线性回归的“参数 → Loss → 梯度 → 更新”链，也为后续理解神经网络的 `z=wX+b`、反向传播与优化提供最简模型。

在电子鼻中，若目标 `y` 是气体浓度，任务是回归：

```text
传感器阵列响应
→ [[电子鼻信号处理]] 提取特征 X
→ 线性回归 / Ridge / Lasso 等回归模型
→ 预测连续浓度
→ MAE / RMSE 等评价
```

这与 [[电子鼻模式识别]] 中“识别类别”的分类任务不同。模型是否适合具体电子鼻数据，仍要通过一致的数据划分、预处理、评价与调参来检验。

## 本次纠正的错误理解

1. **线性回归是无监督学习。** → 它使用 `X + y`，属于监督回归。
2. **导数会直接更新参数。** → 导数给出方向，梯度下降等优化过程执行更新。
3. **`LinearRegression` 必定运行普通梯度下降。** → 常见实现通常以最小二乘数值方法求解。
4. **MSE 只能是 Loss 或只能是 Metric。** → 公式可在不同阶段承担不同角色。
5. **线性模型不会过拟合。** → 高维、少样本或噪声场景中同样可能过拟合。
6. **L1、L2 只是两种写法。** → L1 更可能产生 0 权重；L2 多为整体收缩。
7. **`alpha` 越大越好。** → 过强正则化会导致欠拟合。
