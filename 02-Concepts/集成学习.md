# 集成学习：从 Bagging、随机森林到 AdaBoost、GBDT 与 XGBoost

> [!summary] 一句话理解
> 集成学习不是某一个单独模型，而是把多个模型组合起来的思路：Bagging 让多个相对独立的模型学习不同数据后再汇总，Boosting 则让模型依次训练、不断修正当前模型的不足。

## 本次学习定位

本次学习建立在 [[KNN]] 和 [[决策树]] 之上。它把“单棵树容易因训练数据变化而不稳定”和“如何控制过拟合”的问题，扩展为两条主线：

```text
Decision Tree
→ Ensemble Learning
├─ Bagging：相对独立训练后汇总
│  └─ Random Forest：Bagging Tree + 特征随机性
└─ Boosting：串行训练、逐步纠错
   ├─ AdaBoost：提高错样本权重
   └─ GBDT：学习当前预测的修正量 / 负梯度
      └─ XGBoost：强化 Gradient Boosting 的具体实现
```

## 我的原始疑惑

- Bagging 是否就等于“有放回抽样”？为什么必须有放回？
- 多棵树的超参数可不可以相同；数据和超参数相同时，模型是否一定一致？
- Bagging 已经随机抽样，Random Forest 为什么还要随机候选特征？为什么 `max_features=1` 会造成很大差异？
- AdaBoost 怎样真正“重点关注”预测错误的样本？Sample Weight 与 Learner Weight 分别做什么？
- GBDT 中“训练一棵新回归树学习上一轮残差”是什么意思；为什么输入仍是原始 `X`，而目标换成修正量？
- GBDT 为什么常用回归树，即使最终任务是分类？Residual 与 Negative Gradient 是什么关系？
- XGBoost 和 GBDT 是两个独立算法，还是同一家族的不同实现？

## 我的当前理解

### 集成学习的总思想

多个模型的错误如果不完全相同，合并输出可能比单一模型更稳定或更强。但集成学习不等于“训练很多棵树并投票”；核心分为 Bagging 与 Boosting 两种训练关系。

| 路线 | 模型关系 | 核心目的 | 分类汇总 | 回归汇总 |
| --- | --- | --- | --- | --- |
| Bagging | 相对独立、可并行 | 制造有差异的模型，降低单模型不稳定性 | 多数投票 | 平均 |
| Boosting | 前后串行、相互依赖 | 后一个模型修正当前不足 | 加权组合或累加后判别 | 逐步累加修正 |

最短记忆：Bagging 是“大家独立做题，最后汇总”；Boosting 是“大家排队改同一份答案”。

## Bagging：Bootstrap + 独立训练 + Aggregating

### Bagging 不等于有放回抽样

Bagging 全称为 Bootstrap Aggregating，其完整过程是：

```text
原始训练集
→ Bootstrap Sampling × N
→ N 个不同训练子集
→ N 个基学习器相对独立训练
→ N 个预测
→ 分类多数投票 / 回归平均
→ 最终预测
```

Bootstrap（有放回抽样）只是制造数据差异的一步；Aggregation（聚合输出）同样不可少。

如果对 `A B C D E F` 不放回地抽取 6 个样本，最后仍是同一批样本，只是顺序不同。决策树基本不关心样本排列，因此各树实际看到的数据没有实质差异。反之，有放回抽样可能产生：

```text
Tree 1：A A C D F F
Tree 2：A B B C E F
Tree 3：B C C D D E
```

同一大小的训练集会同时出现重复样本和未抽到的样本，从而让树学习到不同的切分规则。关键因果链是：

```text
Bootstrap
→ 训练数据不同
→ 基学习器不同
→ 错误不完全相关
→ 汇总可能更稳定
```

### 基学习器、超参数与随机性

被反复训练并最终组成集成的单个模型称为 Base Learner / Base Estimator。Bagging 中可以让每棵 [[决策树]] 使用相同的 `max_depth`、`criterion` 等超参数；只要各自使用的 Bootstrap 数据不同，最终树仍可能不同。

进一步的纠正是：即使数据和超参数相同，模型也未必完全相同，还取决于算法内部随机过程、并列候选处理、随机种子和底层数值计算。`random_state=42` 的作用是固定可控随机过程，便于复现实验；它不是让模型“更准确”的参数。

## Random Forest：样本随机性 + 特征随机性

随机森林可以暂时理解为：**决策树 Bagging + 每个节点的随机候选特征**。

Bagging 只改变各树接触的样本。如果一个强特征 `A` 总是最优，很多树仍可能在根节点都选择 `A`，导致树形相似、错误相关性高，投票收益降低。随机森林在每一个节点准备切分时，只随机允许查看一部分候选特征，从而主动制造更多树间差异。

```text
每棵树：Bootstrap 抽样得到训练集
→ 当前节点随机抽取部分候选特征
→ 只在候选特征中寻找最佳“特征 + 阈值”
→ 对子节点重复
→ 多棵树分类投票 / 回归平均
```

重要纠正：不是“一棵树开头随机选一组特征并永久只能使用它们”；而是**每个节点**准备切分时都会重新随机产生候选特征集合。

当 `max_features=1` 时，每个节点只能在随机拿到的一种特征中切分。根节点的一点差异会改变左右子节点中的样本组成，进而影响下一层的候选与最优切分，差异会逐层放大。它平衡的是：

```text
max_features 小 → 树更有多样性，但单树可能变弱
max_features 大 → 单树更易找到强特征，但树可能太相似
```

### OOB 与特征重要性：当前只建立位置

某棵树的 Bootstrap 数据没有抽到的原始样本，称为 OOB（Out-of-Bag，袋外）样本；它们可用于内部性能估计。本次只建立用途直觉，尚未学习严格的 OOB 统计原理。

`feature_importances_` 可帮助观察随机森林在切分中相对依赖哪些特征。例如对电子鼻特征，最大响应值或曲线面积可能显示更高的重要性。重要边界：**特征重要性高只表示模型更依赖它，不表示已经证明因果关系。**

随机森林继承树模型的阈值切分特点，通常不像 [[KNN]] 那样必须标准化；这不意味着可以忽略缺失值、异常值、数据泄漏或实验协议。

```python
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(
    n_estimators=100,
    max_features="sqrt",
    max_depth=10,
    bootstrap=True,
    random_state=42,
)
```

| 参数 | 当前理解 |
| --- | --- |
| `n_estimators` | 森林中树的数量 |
| `max_features` | 每个节点允许查看的候选特征数量 |
| `max_depth` | 每棵树允许的最大深度 |
| `bootstrap` | 是否使用 Bootstrap 抽样 |
| `oob_score` | 是否利用 OOB 样本作内部估计 |
| `random_state` | 控制可复现随机性 |

## Boosting：串行地修正不足

Bagging 中的模型相对独立，后一棵树不需要知道前一棵树犯了什么错。Boosting 则按顺序训练：当前模型先给出答案，下一模型依据当前不足继续补充；最终模型是按顺序叠加的结果。

### AdaBoost：关注错样本

AdaBoost（Adaptive Boosting）通过动态调整 Sample Weight（样本权重），让被上一轮错分的样本在下一轮训练中更受关注。

```text
初始：所有样本权重相同
→ 弱学习器 1 预测
→ 错分样本权重上升
→ 弱学习器 2 更重视这些样本
→ 重复多轮
→ 按学习器可靠程度加权组合
```

它常用非常浅的 Decision Stump（通常一次切分的树）作为弱学习器：单个模型只解决一部分问题，多个弱学习器依次补错后形成较强模型。

本次必须区分两种权重：

| 权重 | 作用 |
| --- | --- |
| Sample Weight | 决定下一轮训练重点关注哪些样本 |
| Learner Weight | 决定最终组合预测时更相信哪个弱学习器 |

标签错误或异常样本可能在许多轮中持续被错分、权重不断升高，使后续模型过度追逐噪声。因此 AdaBoost 可能对噪声和错误标签敏感。

## GBDT：学习“还应修多少”

GBDT（Gradient Boosting Decision Tree）仍是 Boosting，但与 AdaBoost 的“错样本更受关注”不同：它让新树直接学习当前预测需要的连续修正量。

### 最重要的数据流

```text
原始特征 X
→ 当前模型预测 ŷ
→ 计算残差 / 负梯度 r
→ 构造新的训练任务 (X, r)
→ 新回归树学习 X → r
→ 输出修正量 h_m(X)
→ 旧预测 + learning_rate × 修正量
→ 新预测
```

若真实房价为 `y=[100, 150, 200]`，初始预测都是 150，则平方误差下的残差 $r=y-\hat y$ 是：

| 样本 | `y` | 当前预测 `ŷ` | 残差 `r` | 含义 |
| --- | ---: | ---: | ---: | --- |
| A | 100 | 150 | -50 | 当前预测高了 50，应向下修 |
| B | 150 | 150 | 0 | 当前预测正确 |
| C | 200 | 150 | +50 | 当前预测低了 50，应向上修 |

下一棵树**不是**重新学习 `X → [100, 150, 200]`，而是学习 `X → [-50, 0, +50]`：什么样的输入需要向上修、向下修或不修。新树给出修正后，例如对 A：`150 + (-50) = 100`。

在平方误差回归中：

$$
L=\frac{1}{2}(y-\hat y)^2
$$

$$
-\frac{\partial L}{\partial \hat y}=y-\hat y=r
$$

因此“拟合负梯度”恰好等价于“拟合残差”。但这只在平方误差等特定损失下成立；更一般地，GBDT 拟合的是当前 Loss 对预测值的负梯度，所以它叫 Gradient Boosting，而不应永远简化为 Residual Boosting。

即使最终任务是分类，新树内部也常需要输出连续修正量如 `+0.3` 或 `-0.7`，因此基学习器通常是回归树。总模型可先理解为：

$$
F_m(x)=F_{m-1}(x)+\eta h_m(x)
$$

其中 $\eta$ 是 `learning_rate`，控制每棵新树修正当前模型的力度；`learning_rate` 越小，每一步越谨慎，通常也需要更多 `n_estimators`。

GBDT 与普通梯度下降的共同直觉是“沿着能让 Loss 下降的方向修正”；不同在于它不是反复调一棵树的既有参数，而是不断加入新树来修正整体预测函数。

## XGBoost：强化的 Gradient Boosting

XGBoost（Extreme Gradient Boosting）不是脱离 GBDT 的新体系，而是 Gradient Boosting 家族中的一种具体强化实现。它仍通过新树逐步修正模型，但更明确地把预测误差和模型复杂度同时放进目标：

$$
Objective=Loss+Regularization
$$

这与 [[决策树]] 中“控制树复杂度以避免过拟合”的思想一致：不能只为了微小训练 Loss 改善而长出过度复杂的树。

当前只需建立概念位置：它会使用一阶梯度（修正方向）和二阶信息（损失局部曲率 / 梯度变化）协助建树，并常提供样本与特征采样、正则化和工程优化。不要在当前阶段推导 Taylor Expansion、叶节点权重或 Gain 公式。

```python
from xgboost import XGBClassifier

model = XGBClassifier(
    n_estimators=100,
    learning_rate=0.05,
    max_depth=3,
    subsample=0.8,
    colsample_bytree=0.8,
    random_state=42,
)
```

| 参数 | 当前理解 |
| --- | --- |
| `n_estimators` | 依次加入多少棵树 |
| `learning_rate` | 每棵树的修正力度 |
| `max_depth` | 每棵树最大深度 |
| `subsample` | 每轮使用的样本比例 |
| `colsample_bytree` | 每棵树使用的特征比例 |
| `random_state` | 控制随机性 |

即使 Random Forest 和 XGBoost 都可能有样本 / 特征采样，也不能据此把它们当作同一思路：前者属于 Bagging，主要依赖相对独立树的汇总；后者属于 Boosting，树之间是串行依赖的。

## 四种模型的比较

| 算法 | 模型关系 | 核心动作 | 下一模型主要做什么 |
| --- | --- | --- | --- |
| Random Forest | 相对独立 | Bootstrap + 特征随机性 + 投票/平均 | 不依赖前一棵树的错误 |
| AdaBoost | 串行 | 提高错样本权重 | 更关注前面分错的样本 |
| GBDT | 串行 | 累加树的连续修正量 | 拟合当前负梯度 / 残差 |
| XGBoost | 串行 | 强化的 Gradient Boosting | 结合梯度、正则化、采样与工程优化建树 |

```text
Random Forest：大家独立做题，最后投票
AdaBoost：哪些题错了，下一位重点看
GBDT：当前答案差多少，下一棵树直接学怎么改
XGBoost：仍然逐步改，但更显式控制复杂度、利用更丰富的损失信息
```

## 与已有知识和电子鼻研究的关系

集成学习不是与 [[决策树]] 并列的孤立概念。随机森林由许多差异化决策树组成；GBDT 中每棵新树都可看作学习“原始特征 `X` → 连续修正量”的回归树。后者直接连接到决策树中的 CART 回归树：树学习的机制不变，变化的是目标从原始 `y` 变成当前模型所需的修正目标。

在电子鼻的传统机器学习流程中，[[电子鼻信号处理]] 可将多通道响应变为特征或表示，[[电子鼻模式识别]] 再可使用树模型及集成方法输出气体类别、浓度或状态。

```text
传感器响应
→ 特征提取 / 表示学习
→ 特征矩阵 X
→ Random Forest / AdaBoost / GBDT / XGBoost
→ 气体类别、浓度或状态
```

对表格型、多传感器和人工特征数据，这些模型是值得纳入比较的传统基线候选；但“某模型效果更好”不是预设结论。实际比较必须统一数据划分、预处理、评价指标、交叉验证和调参预算。

## 本次纠正的错误理解

1. **Bagging 就是有放回抽样。** → Bootstrap 只是制造数据差异的一步；Bagging 还要求训练多个基学习器并聚合输出。
2. **同超参数的树一定一样。** → 训练数据和随机过程不同即可产生不同树。
3. **随机森林只在树开始时随机一次特征。** → 每个节点都会重新抽取候选特征。
4. **AdaBoost 只有一种权重。** → 样本权重控制下一轮训练重点，学习器权重控制最终组合影响力。
5. **GBDT 新树重新拟合原始标签。** → 输入 `X` 保持不变，但新训练目标改成负梯度 / 特定情形下的残差。
6. **GBDT 永远就是残差学习。** → 一般形式是负梯度学习；残差仅在平方误差等情形下等价。
7. **XGBoost 与 GBDT 完全无关。** → XGBoost 属于 Gradient Boosting 家族，是强化的具体实现。
