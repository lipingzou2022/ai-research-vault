# 电子鼻

## 我的当前理解

电子鼻是一类模拟嗅觉识别过程的检测系统。它利用多个气体传感器形成响应模式，再通过信号处理和模式识别判断气体类别、浓度或样本状态。

## 为什么需要它

计算机不能直接理解气味。电子鼻把气体与敏感材料的相互作用转换成可测量的电学信号，使气味识别成为可以采集数据、训练模型和评价结果的计算问题。

## 系统主线

```text
真实气体
→ [[气体传感器阵列]]
→ 电阻、电压等响应信号
→ [[电子鼻信号处理]]
→ [[电子鼻模式识别]]
→ 气体类别、浓度或样本状态
```

## 主要任务

- 定性分析：判断“是什么”，通常对应分类问题。
- 定量分析：判断“有多少”，通常对应回归问题。
- 状态判断：根据气味模式判断疾病、食品新鲜度或污染状态。

## 主要应用

- 环境污染与有毒气体检测；
- 呼气疾病辅助检测；
- 食品质量、安全和真实性判断。

## 关键困难

- [[传感器漂移]]；
- [[混合气体识别]]；
- 湿度和其他环境因素干扰；
- 跨设备、跨阵列和跨时间泛化；
- 高质量标注数据不足。
